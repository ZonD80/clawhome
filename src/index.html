Use your ChatGPT plan

bia itself is free. With ChatGPT, bia's requests count toward your ChatGPT plan's limits. Nothing is charged by bia.

Or use an API key

How do I get an API key?
  1. Open the provider's page and sign up (or sign in).
  2. Add a little credit with a card. A few dollars lasts a long time.
  3. Press "Create key", copy the key, and paste it here.

OpenRouter (easiest)

One key for almost every AI: Grok, Claude, GPT, DeepSeek, Qwen and more. Best place to start.

OpenAI (GPT)

The makers of ChatGPT. Have ChatGPT Plus or Pro? Skip the key and press Continue with ChatGPT instead. An API key is billed separately.

Anthropic (Claude)

The makers of Claude. A Claude.ai subscription does not include this. API credit is bought separately.

xAI (Grok)

The makers of Grok. Add credit in the console, then create a key.

DeepSeek

Low prices. Top up first, then create a key.

Qwen (Alibaba Cloud Model Studio)

Alibaba's Qwen models. Create the key in Model Studio. New accounts may get free trial tokens.

The key is saved on the home's disk so bia can use it. Keep that disk safe, like a house key.

Checked with a real request before the home is created. A model that cannot call tools is rejected. The key is then stored in plaintext at EFI/bia/fmm.json on the disk. A ChatGPT sign-in is for this home only.
